# CUET Pro — Learning Dashboard

CUET Pro student platform dashboard — design preview (Phase 1).

## Current
- `index.html` — standalone dashboard design preview (navy + green brand, mobile-first)
- Sample data only — live data arrives with Supabase backend (Phase 3+)

## Roadmap
1. Foundation (design system, shell) ← **current**
2. Auth + Onboarding (Google login, subjects, diagnostic test)
3. Dashboard (live data)
4. Study Kit (Notes, PYQs, Mocks, Topic Tests, Flashcards)
5. Practice (question engine)
6. Analysis (analytics + recommendation engine)
7. DU Explorer (colleges, cutoffs, compare, targets)
8. Personalization (recommendation v2, streaks)
9. Polish (mobile QA, a11y)
10. Testing + Deploy

## Design system
- Brand: Navy `#1A2C49` + Green `#00C97F`
- Fonts: Sora (display), Plus Jakarta Sans (body), IBM Plex Mono (data)
