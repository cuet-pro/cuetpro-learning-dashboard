If Sentences

+ types 0 to 3

A conditional sentence has an if-clause (condition) and a main clause (result). There are four types, and the tense of the if-clause tells you the type.

1

The Four Types

Zero, first, second and third conditional

Start here: Which conditional? (follow the arrows)

Look at the if-clause verb. It names the type.

1.1  The four types

ZERO  (ALWAYS TRUE)

If + present, present

If you heat water, it boils.

FIRST  (REAL, LIKELY)

If + present, will + V1

If you study, you will pass.

SECOND  (UNREAL, PRESENT)

If + past, would + V1

If I knew, I would tell you.

THIRD  (UNREAL, PAST)

If + had + V3, would have + V3

If I had known, I would have told you.

M E M O R Y   H A C K     |     1 - 2 - 3

1st: present → will. 2nd: past → would. 3rd: had V3 → would have V3. The if-clause tense goes one step back each time.

2

Rules and Variations

Unless, were, mixed types and inversion

2.1  Special if-patterns  (follow the arrows)

These three patterns appear in many exam sentences.

2.2  Rules that win marks

NO WILL AFTER IF

if-clause never takes will / would

If it rains, not if it will rain

UNLESS

already negative, so no not

Unless you work, you will fail

IF I WERE

were for all persons in unreal if-clauses

If he were here, he would help.

MIXED TYPE

past condition, present result

If I had studied, I would be a doctor now.

INVERSION

drop if, move had / were / should

Had she known, she would have come.

PROVIDED / AS LONG AS

mean "only if"

You may go provided you return early.

IN CASE

precaution

Take an umbrella in case it rains.

WISH

unreal present = past, unreal past = had V3

I wish I had time. I wish I had known.

OTHERWISE / OR

imply an if

Hurry up, or you will be late.

E X A M   T R A P S   W I T H

Never use will in the if-clause: If you will come, I will go → If you come, I will go.

 Never use would in the if-clause: If I would know → If I knew.

 Unless + negative is wrong.

MEMORY HACK  |  WOULD STAYS IN THE RESULT

would / would have belong only in the result clause. The if-clause takes the tense, never would.

3.3  Mixed practice: complete the sentence

1.  If it rains, we ___ (will stay / would stay) home.

2.  If I ___ (was / were) you, I would apologise.

3.  If she had studied, she ___ (would pass / would have passed).

4.  Unless you ___ (hurry / do not hurry), you will be late.

5.  If you heat ice, it ___ (melts / will melt).

6.  ___ (Had / Have) I known, I would have helped.

7.  I wish I ___ (have / had) more time.

8.  If I ___ (had / have) a car, I would drive you.

9.  He will help you provided you ___ (ask / will ask).

10.  If I had left earlier, I ___ (would be / will be) there now.

Answers: 1 will stay, 2 were, 3 would have passed, 4 hurry, 5 melts, 6 Had, 7 had, 8 had, 9 ask, 10 would be.
